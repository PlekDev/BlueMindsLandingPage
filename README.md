# 🧠 Neuro-BlueMinds | Enterprise Landing Page

Página web empresarial y de presentación institucional del proyecto **Neuro-BlueMinds**, una plataforma de neuroeducación con IA adaptativa diseñada para la intervención temprana en el Trastorno del Espectro Autista (TEA).

Esta landing page actúa como el rostro corporativo del proyecto, optimizada para networking de alto nivel, difusión institucional y apoyo visual durante la **IFE Conference 2026** en Monterrey, N.L.

---

## 🚀 Propósito Estratégico

- **Presentación Profesional**: Exponer la visión, métricas técnicas (LPR/TEP), impacto social y el equipo detrás del proyecto.
- **Soporte en Eventos**: Servir como recurso interactivo mediante códigos QR en el stand y durante la ponencia.
- **Networking**: Punto de contacto centralizado para inversionistas, instituciones educativas (Tec de Monterrey) y aliados estratégicos.
- **Identidad**: Diferenciar la marca corporativa del entorno funcional del MVP (aplicación de usuario).

> **Nota**: La documentación técnica profunda, arquitectura del backend en .NET, modelos de IA/ML y el desarrollo funcional se encuentran en el repositorio principal del ecosistema Neuro-BlueMinds.

## 🛠 Stack Tecnológico

Para garantizar velocidad de carga inmediata en entornos de alta concurrencia (como congresos), hemos optado por una arquitectura ligera:

- **Frontend**: HTML5 Semántico + [Tailwind CSS](https://tailwindcss.com/) (diseño responsivo "mobile-first").
- **Interactividad**: JavaScript Vanilla con lógica de **SPA (Single Page Application)** para transiciones fluidas sin recarga de página.
- **Visualización de Datos**: [Chart.js](https://www.chartjs.org/) para la representación de métricas neurocognitivas.
- **Assets**: Google Fonts (Inter) y Font Awesome 6 para iconografía técnica.

---

## 📈 Key Features (Métricas de Ingeniería)

La página destaca los dos pilares algorítmicos de nuestra solución:
1. **LPR (Latency Response)**: Medición de tiempos de procesamiento cognitivo.
2. **TEP (Tasa de Error Perseverativo)**: Identificación de bucles de aprendizaje para ajuste dinámico de contenido.
